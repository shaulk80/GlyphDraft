# OCR fixtures

Printed-text test images with the expected text (`<name>.png`, `<name>.txt`, `manifest.tsv` with name, language, script).

They are generated by `spikes/ocr` (`.\gradlew -p spikes/ocr run --args="fixtures"`) from sentences written for this project or public-domain phrases (pangrams; a line from Natsume Soseki's "I Am a Cat", 1905) rendered with system fonts, then skewed, noised or blurred for the photo-like cases. The images contain no third-party artwork and are released under the repository license.

Expected text is in logical order, one line per text line; scoring ignores whitespace.

Handwritten pages are a set of their own with other rules: `handwriting/README.md`.
