# M2: hand-test checklist and results

The owner runs this in task 10, before `/release 0.1.0`. Labels are the exact texts of the UI (read from the source on 2026-11-21). Fill in "Result" (OK, or what you saw) and "Date" per row; findings that need a change go into the Findings table at the end, and each becomes a fix or a GitHub issue before the release. The results are written into this file in the same session in which the owner reports them. How the older M1 screens are exercised is in `docs/manual-testing.md` (still valid for layout, window size, file dialogs and the Android pickers); this file covers what M2 added: real recognition, the first-use download, offline use, settings in a file, the icon and the signed APK.

## Before you start

- Build under test: the Windows zip and the APK of the release dry run (`gh workflow run release.yml --ref main`, artifact `release-preview`, download commands under the H table), or `.\scripts\build.ps1` output in `dist\`. Faster for a first pass: `.\gradlew :desktopApp:run` (the version line then says "GlyphDraft dev"). Final pass: the packaged zip.
- The dry run needs the four `ANDROID_*` secrets (`docs/release-signing.md`); without them its `build-android` job stops at "Prepare the release key" by design and no artifact is produced.
- Version: the app shows, and the files are named after, `appVersion` in `gradle.properties`: 0.0.1 until the release pull request (`/release 0.1.0`) is merged, 0.1.0 after. The steps below say `<appVersion>`. A first pass with 0.0.1 is fine; repeat the version and file-name checks (A3, H4, I1, I2) on the 0.1.0 dry run.
- Test files and the data folder live under `C:\Vibe\z_tmp\GlyphDraftTests` (decision 0003), never in the repo and never `%TEMP%`.
- You need internet for the first download of each model pack and a way to switch it off again (Wi-Fi off, airplane mode or unplugging).

```powershell
$root = "C:\Vibe\z_tmp\GlyphDraftTests"
$env:GLYPHDRAFT_DATA_DIR = "$root\data-m2"          # a fresh, empty data folder for the first-use run
$files = "$root\files"
New-Item -ItemType Directory $files -Force | Out-Null
Copy-Item C:\Vibe\GlyphDraft\engine\src\test\resources\fixtures\*.png $files   # the 11 fixture images
Copy-Item C:\Vibe\GlyphDraft\engine\src\test\resources\fixtures\*.txt $files   # their expected text, to compare by eye
```

The fixtures cover English, German, Russian, Chinese, Japanese and Hebrew, plus one mixed English and Russian image and four photo-like ones (`en-skew`, `ru-noise`, `de-blur`, `zh-noise`). There is no French or Spanish fixture: type the texts from "Test texts" at the end of this file at about 18 to 24 pt, dark on white, take a screenshot of each and save it as `fr.png` and `es.png` in the same folder. The environment variable lasts for that PowerShell window only.

The sizes in the download dialog are in MiB with the label "MB": Latin scripts 12.2 MB, Russian 12.1 MB, Chinese and Japanese 20.5 MB, Hebrew 0.9 MB (the README says "about 13, 13, 22 and 1 MB", which are decimal MB).
